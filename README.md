Dev's Smart To-Do List

A modern, AI-assisted To-Do List app built with React, Tailwind CSS, and Framer Motion.  
It helps you organize tasks, set priorities, track progress, and stay productive with a clean UI.  


Features
- Add, edit, and delete tasks  
- Mark tasks as completed  
- Task prioritization (High, Medium, Low)  
- Set deadlines & reminders  
- Progress tracker with animated UI  
- Local storage persistence (tasks remain after reload)  
- Smooth animations with Framer Motion  

Tech Stack
- React (Vite) – Frontend framework  
- Tailwind CSS – Styling  
- Framer Motion – Animations  
- LocalStorage – Save tasks on device
